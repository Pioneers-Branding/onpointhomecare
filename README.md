# OnPoint Nurse & Home Care

Static HTML website for OnPoint Nurse & Home Care (Vancouver, BC, Canada). Every page is a standalone `.html` document at the root level — there are no build steps, frameworks, or runtime dependencies.

## Website Files

```
index.html             Home page
about-us.html          About Us
services.html          Elder Care Services
dementia-care.html     Dementia & Memory Care
our-care-team.html     Clinical Leadership & Care Team
resources.html         Family Guides & Resources
faqs.html              Frequently Asked Questions
contact.html           Contact Page
care-assessment.html   Book a Care Assessment Wizard
styles.css             Main CSS stylesheet
app.js                 Interactive client-side JS (drawer, accordions, wizard, modals)
assets/                Images, icons, and logos
```

## Running Locally

You can open any `.html` file directly in your web browser (by double clicking it or using `file://`), or run a local server:

```
npm run serve
```
